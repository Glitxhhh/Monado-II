Monado II launcher AppImage notices

This image contains only the authored native launcher, its small workspace
driver, desktop metadata, original II icon and license notices. It contains no
game input, generated game code, game executable, game shaders/caches, saves,
private SDK, development sysroot or copied system library. It needs its adjacent
Monado_Linux workspace, existing local dependency setup and locally built game.
The source kit distributes no AppImage/runtime executable; users generate the
image locally. Do not publish a local image without reviewing all its contents.
