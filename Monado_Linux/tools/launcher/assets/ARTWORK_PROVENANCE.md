# Launcher illustration provenance

`gaur_plain.png` is the original standalone illustration generated for this
launcher in the maintainer's Codex session on November 5, 2026, using OpenAI's image
generation tool and the maintainer's generated UI concept as a visual reference.
The maintainer requested its restoration and publication with Monado II.

- SHA-256: `4a863642bba750089667e10727cf72353875a7baf80a0903911e47d897d8fd0a`.

with a red sword and cyan circular opening in the left foreground, grass, distant
cliffs and a wide sky. It excluded characters, UI, text, branding and watermarks.
The image is presentation artwork, not a copy of a game file or a screenshot.
